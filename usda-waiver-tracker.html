About

USDA SNAP Time Limit Waiver Tracker monitors the USDA Food and Nutrition Administration page that lists state requests and FNS/FNA responses for Able-Bodied Adults Without Dependents (ABAWD) time limit waivers.

It shows which states have a response posted for the current federal fiscal year, lists linked PDFs, and (after your first successful check) reports what changed since the last time you ran an update.

  • Data is read from the public USDA page you configure (default: FY 2025–2029 time limit waivers).
  • Settings, email preferences, and the change baseline are stored only in this browser (localStorage).
  • Nothing is sent to a third-party server except when you explicitly use EmailJS or Formspree, or when the page tries public CORS proxies to load the USDA HTML.

Recommended for organizations: run the free fetch_waivers.py scraper on a daily GitHub Actions schedule and set the resulting waivers.json URL under Settings → Data feed URL. The tracker then updates without CORS or manual paste.

Without a data feed, browsers block direct reads of USDA sites. Use Settings → Paste page source as a manual fallback.

Source of truth: the linked PDFs on the USDA site. Status labels here summarize what is posted, not the legal approval text inside each document.
